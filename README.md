### 🔌 Custom Plugins

| Plugin | Purpose |
|---|---|
| **FolderManager** | Advanced Discord folder customization |
| **NoPause** | Prevents unwanted stream/audio pausing |
| **Timer** | Embedded status and activity timer |
| **Safe Console** | Cleaner developer console logging |
